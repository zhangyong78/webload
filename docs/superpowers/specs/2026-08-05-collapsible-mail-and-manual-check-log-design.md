# 邮件配置折叠与手动检查日志设计

## 目标

缩小邮件配置对窗口纵向空间的占用，让运行日志默认显示更多内容，并让用户点击“立即检查”后明确知道程序正在同时检查 OKX 活动与 A 股可转债申购。

## 界面设计

- “邮件配置”改为带方向箭头的可折叠区域，程序启动时默认收起。
- 收起时只显示“邮件配置”标题；点击后展开 SMTP Host、SMTP Port、SMTP 用户名、SMTP 密码、发件邮箱、收件邮箱和“使用 SSL”。
- 删除界面中的“qqokx 项目路径”输入行。`AppConfig.qqokx_project_path` 继续保留，供自动导入和“从 qqokx 导入邮件”按钮内部使用，默认值仍为 `D:\qqokx`。
- 运行日志设置最小可用高度，并继续占用左栏剩余空间；邮件配置收起后，释放的高度全部归运行日志。

## 检查与日志流程

- “立即检查”继续调用统一的 `run_monitor_cycle`，因此一次请求同时检查 OKX 活动和当日可转债申购。
- 手动检查被接受后，后台线程启动前立即记录：`开始检查（手动）：正在检查 OKX 活动和 A 股可转债申购。`
- 检查结束后保留现有两类结果日志：OKX 检查结果，以及 `可转债检查完成（手动）：今日无可申购转债。` 或当日可申购数量。
- 10:00、14:00 的可转债提醒时点、补发规则、提醒去重和通知渠道均不改变。

## 错误处理

- 可转债接口失败时仍显示现有的 `可转债检查失败（手动）: ...`。
- 已暂停或已有检查正在执行时，保持现有行为，不启动第二个并发检查。
- 删除路径输入框后，导入操作使用配置中的路径；空值回退为 `D:\qqokx`。

## 测试

- 使用真实 Qt 控件验证邮件区域默认收起、点击可展开、日志最小高度生效，并且不存在 qqokx 路径输入控件。
- 调用真实 `MainWindow.check_now` 方法，隔离后台线程，验证手动检查开始日志在工作线程启动前写入。
- 运行全量 pytest，并重新生成 Windows EXE。
